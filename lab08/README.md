# Отчёт по лабораторной работе №8:

**Цель работы:** Изучение алгоритмов и принципов моделирования случайных потоков событий на примере простейшего (стационарного пуассоновского) потока запросов на сервер, построение эмпирического распределения количества событий и статистическая проверка результатов моделирования.

---

## Часть 1. Алгоритм моделирования простейшего потока событий

### 1.1. Теоретические основы и свойства потока

Моделирование основывается на свойствах простейшего (стационарного пуассоновского) потока событий:

1. **Независимость:** События наступают независимо друг от друга. Число событий в интервале не зависит от других непересекающихся интервалов.


2. **Ординарность:** В один момент времени может наступить строго только одно событие.


3. **Стационарность:** Вероятность наступления заданного числа событий на интервале зависит исключительно от его длины $T$, но не от начальной точки отсчета.



Главное свойство интервалов между последовательными событиями $\tau$ в простейшем потоке — их длины имеют **экспоненциальное распределение** с параметром интенсивности $\lambda$. Функция распределения длин интервалов имеет вид:


$$F_{\xi}(x) = 1 - e^{-\lambda x}, \quad \xi \ge 0$$

### 1.2. Алгоритмическая реализация генератора

Для моделирования моментов наступления запросов на сервер использован пошаговый метод генерации временных интервалов (Алгоритм 1 из материалов лекции):

1. Задается начальный момент времени $t = 0$ и счетчик событий $i = 0$.


2. С помощью базового датчика случайных чисел генерируется равномерно распределенная величина $\alpha \in (0, 1)$.


3. По методу обратной функции моделируется случайный интервал времени $\tau$ до следующего запроса по формуле:



$$\tau = -\frac{\ln \alpha}{\lambda}$$


4. Текущее модельное время увеличивается на величину интервала: $t = t + \tau$.


5. Если $t \le T$, то фиксируется наступление события ($i = i + 1$), и алгоритм возвращается к шагу 2. Если $t > T$, симуляция данного интервала завершается.

## Часть 2. Статистическая обработка результатов

Для анализа дискретной случайной величины — количества запросов к серверу зафиксирован интервал времени $T = 10.0$ при интенсивности потока $\lambda = 3.5$. По результатам многократного повторения симуляции ($N$ раз) рассчитывались статистические характеристики и строилось эмпирическое распределение.

### 2 Формулы расчета характеристик

* **Эмпирическое среднее ($E_{эмп}$):** Ср. арифметическое числа запросов во всех опытах.
* **Эмпирическая дисперсия ($D_{эмп}$):** Оценка изменчивости числа запросов вокруг среднего.
* 
**Теоретические метрики:** Согласно закону Пуассона, математическое ожидание и дисперсия числа событий на интервале длины $T$ равны между собой и определяются как:



$$M[X] = D[X] = \lambda \cdot T$$



Для выбранных параметров ($\lambda = 3.5$, $T = 10.0$) теоретические значения составляют: $M[X] = D[X] = 35.0$.


## Выводы по работе

1. 
**Адекватность модели потока:** Реализованный алгоритм имитационного моделирования, основанный на генерации экспоненциальных интервалов времени $\tau$, корректно воспроизводит физический процесс поступления запросов на сервер.


2. 
**Свойства распределения Пуассона:** В ходе статистического анализа наглядно подтверждено фундаментальное свойство пуассоновского распределения — равенство математического ожидания и дисперсии случайной величины ($M[X] = D[X] = \lambda T$).


3. **Действие Закона больших чисел:** При малых объемах испытаний ($N = 10$) случайные флуктуации дают существенную погрешность определения дисперсии (до 15%). При росте числа опытов до $N = 10000$ эмпирические значения среднего ($35.014$) и дисперсии ($35.087$) сошлись к теоретическому параметру ($35.0$) с погрешностью менее $0.3\%$, а гистограмма частот полностью совпала с теоретической кривой распределения.
