# Отчёт по лабораторной работе 10

**Цель работы:** Изучение принципов имитационного дискретно-событийного моделирования систем массового обслуживания (СМО) типа M/M/c/K, реализация алгоритмов обработки заявок с учетом ограничений вместимости системы и нетерпеливости клиентов, а также сравнительный анализ теоретических и эмпирических характеристик системы.

---

## Часть 1. Математическая модель и алгоритм работы СМО

### 1.1. Теоретические основы и свойства системы

Моделируемая система описывается нотацией Кендалла **M/M/c/K** с дополнительным правилом нетерпеливости (reneging):
1. **Входящий поток (M):** Стационарный пуассоновский поток с интенсивностью $\lambda = 5.0$. Интервалы между прибытиями $\tau_{arr}$ имеют экспоненциальное распределение: $F(\tau) = 1 - e^{-5.0 \tau}$.
2. **Время обслуживания (M):** Экспоненциальное распределение с интенсивностью $\mu = 2.0$ для каждого из $c = 3$ приборов.
3. **Ограниченная вместимость (K):** Максимальное число заявок в системе не может превышать $K = 10$.
4. **Нетерпеливость заявок:** Среднее время терпения $T_{pat} = 2.0$ ед. времени.

### 1.2. Алгоритмическая реализация обработки заявки

Для моделирования использован метод дискретно-событийного моделирования (библиотека SimPy). Алгоритм обработки одной заявки:

1. **Прибытие:** Генерация заявки в момент $t_{arr}$ по экспоненциальному закону с параметром $\lambda = 5.0$.
2. **Проверка вместимости:** Если $N_{queue} + N_{busy} \ge 10$, заявка получает отказ.
3. **Генерация терпения:** $P = -2.0 \cdot \ln(\alpha)$, где $\alpha \in (0, 1)$.
4. **Ожидание ресурса:** Конкуренция двух событий — освобождение прибора или истечение времени $P$.
5. **Исход:** Успешное обслуживание или уход из очереди (ренегат).

## Часть 2. Сравнительный анализ результатов моделирования

### 2.1. Теоретические характеристики (базовая модель M/M/c/K без ренегатов)

Расчет выполнен аналитически через систему уравнений равновесия:

**Основные параметры:**
- Приведённая нагрузка: $A = \lambda / \mu = 5.0 / 2.0 = 2.5$ эрланг
- Коэффициент загрузки: $\rho = \lambda / (c \cdot \mu) = 5.0 / (3 \cdot 2.0) = 0.8333$ (83.33%)

**Вероятности состояний:**
- $P(\text{система пуста}) = p_0 = 0.0537$
- $P(\text{все приборы заняты}) = 0.6441$
- $P(\text{отказ}) = p_K = 0.0390$ (3.90%)

**Средние характеристики:**
- Среднее число заявок в системе: $L = 4.0614$
- Среднее число занятых приборов: $L_s = 2.4024$
- Средняя длина очереди: $L_q = 1.6590$

**Временные характеристики:**
- Эффективная интенсивность: $\lambda_{eff} = 4.8048$
- Среднее время ожидания: $W_q = 0.3453$ ед. времени
- Среднее время пребывания: $W = 0.8453$ ед. времени

### 2.2. Эмпирические характеристики (имитационная модель с нетерпеливостью)

По результатам моделирования в течение $T_{sim} = 100$ ед. времени:

**Общая статистика:**
- Всего прибыло заявок: $N_{arr} = 473$
- Успешно обслужено: $N_{serv} = 424$ (89.6%)
- Получили отказ: $N_{rej} \approx 4$ (0.8%)
- Ушли из очереди: $N_{ren} \approx 43$ (9.1%)
- Среднее время ожидания (эмпирическое): $W_q^{имит} = 0.2004$ ед. времени

**Распределение исходов (по круговой диаграмме):**
- Обслужено: 90.0%
- Ушли из очереди: 9.1%
- Отказ: 0.8%

## Выводы по работе

1. **Адекватность имитационной модели:** Реализованный алгоритм корректно воспроизводит логику работы многоканальной СМО с конечной очередью. Механизм конкурирующих событий (`yield req | timeout`) в SimPy точно моделирует поведение нетерпеливых заявок, разделяя потоки потерь на «отказы» и «ренегаты».

2. **Количественная оценка влияния нетерпеливости:** Сравнение теоретических и эмпирических данных демонстрирует существенный эффект нетерпеливости:
   - **Среднее время ожидания сократилось на 42%** (с 0.3453 до 0.2004), что объясняется тем, что нетерпеливые заявки не дожидаются пиковых нагрузок.
   - **Доля успешно обслуженных заявок снизилась** с теоретических 96.1% до 90.0%, при этом 9.1% заявок ушли из очереди по собственному желанию.
   - **Вероятность отказа уменьшилась** с 3.9% до 0.8%, так как нетерпеливые заявки освобождают места в очереди для других клиентов.

3. **Интерпретация графиков:**
   - **Гистограмма вероятностей состояний** показывает, что наиболее вероятное состояние системы — 2-3 заявки (пик около $n=2$), что согласуется с приведённой нагрузкой $A = 2.5$ эрланг.
   - **График динамики очереди** демонстрирует высокую волатильность: длина очереди колеблется от 0 до 7, но среднее значение (синяя гистограмма) находится ниже теоретической линии $L_q = 1.66$ (красный пунктир), что подтверждает разгружающий эффект нетерпеливости.
   - **Столбчатая диаграмма сравнения** наглядно показывает, что имитация даёт меньшую вероятность обслуживания и меньшую вероятность отказа по сравнению с теорией, а разница компенсируется категорией «ушли из очереди».

4. **Практическая значимость:** Результаты показывают, что при проектировании реальных систем (кол-центры, сервисные центры) необходимо учитывать фактор нетерпеливости клиентов. Игнорирование этого фактора (использование только классической теории M/M/c/K) приведёт к завышенной оценке времени ожидания и неверному планированию ресурсов.

5. **Статистическая достоверность:** При времени моделирования $T = 100$ ед. времени и общем числе заявок $N = 473$ получена репрезентативная выборка. Для повышения точности оценок рекомендуется увеличить время моделирования до $T \ge 1000$, что обеспечит обработку более 4000-5000 заявок и снизит статистическую погрешность.

**Общий вывод:** В ходе лабораторной работы успешно реализована имитационная модель СМО M/M/c/K с усложнениями (ограниченная вместимость и нетерпеливость заявок). Проведён сравнительный анализ с теоретическими характеристиками классической системы, количественно оценено влияние фактора нетерпеливости на основные показатели эффективности системы.
